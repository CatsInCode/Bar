# Barmen WebApp (MVP)

Веб‑приложение для бармена:
- **Рецепты**: хранение/создание/редактирование, поиск по названию.
- **Мероприятия**: карточка мероприятия + сбор барной карты из рецептов (с количеством порций).
- **Каталог закупки**: «словарь» для красивого WhatsApp‑формата (секции 1.0–6.0, бренды, ссылки, округление по бутылкам/пачкам).
- **Заказы**: таблица заказов как в Excel, но **связана** с мероприятием (кнопка «WhatsApp» берёт список закупки оттуда).

## Запуск
```bash
npm i
npm run dev
```

## Firebase
Используется Firebase Realtime Database (уже подключено в `src/firebase.ts`).

Если RTDB URL у проекта другой — задай `VITE_FIREBASE_DATABASE_URL` в `.env`.

> Важно: проверь правила доступа в RTDB (Security Rules). Для MVP можно временно открыть, но лучше добавить авторизацию и правила.

## Импорт рецептов из твоего `рецепты.txt`
Скрипт парсит TSV из Excel и выдаёт JSON:
```bash
node ./scripts/parseRecipesTxt.mjs ./рецепты.txt > recipes.json
```

Дальше можно будет написать маленький импортёр в RTDB (следующий шаг).


## Ручные строки в WhatsApp
В карточке мероприятия есть блок «Доп. позиции для WhatsApp (ручной ввод)» — туда можно вставлять аренду/лёд/итоги и любые строки, которые должны сохраниться *ровно* с форматированием.

## Шаблон каталога
В папке `sample_data/` есть `sampleCatalog.json` — это заготовка под формат из твоего примера (бренды/ссылки). Можно использовать как основу.
